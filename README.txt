WILD FANFEST 현장용 태블릿 상품 카탈로그

실행 방법
1. index.html을 태블릿 브라우저에서 엽니다.
2. 현장 운영 시 브라우저의 전체 화면 또는 홈 화면 추가 기능을 사용하면 좋습니다.

화면 구성
- 총 상품 수: 89개
- 태블릿 가로 화면: 4열
- 태블릿 세로 화면: 3열
- 스마트폰 화면: 2열
- 상품 터치 시 큰 이미지 팝업 표시
- 한글 상품명 / 영문 상품명 / 판매가 표시
- 상품명 검색 지원
- 터치 오작동 방지 및 이미지 드래그·길게 누르기 방지

상품 수정
index.html 내부의 products 배열을 수정하세요.

예시:
{
  id: 1,
  nameKo: "한글 상품명",
  nameEn: "ENGLISH PRODUCT NAME",
  price: "39,000원",
  image: "./images/product01.jpg",
  badge: "NEW",
  description: "상품 상세 설명"
}

이미지 권장 규격
- 정사각형 1000 × 1000px
- JPG, PNG 또는 WebP
- images 폴더에 저장 후 "./images/파일명.jpg" 형식으로 연결


적용 데이터
- 제품리스트.xlsx의 제품명, 영문명, 판매가를 적용했습니다.
- 표기 특이사항은 상품 이미지 좌측 상단의 스티커로 표시됩니다.
- 쇼핑백 3종은 상품 진열 수 89개에서 제외했습니다.


관리자 기능
- 페이지 맨 아래의 관리자 버튼을 누릅니다.
- 비밀번호: 2026
- 한글 상품명, 영문 상품명, 가격 수정 가능
- 품절 버튼 사용 시 이미지가 회색 블러 처리되고 SOLD OUT이 표시됨
- 저장한 내용은 해당 태블릿 브라우저의 localStorage에 저장됨
- 브라우저 데이터 삭제 또는 초기 데이터 복원 시 수정 내용이 사라질 수 있음
